# Турнир "Решись" — Прогноз спроса на авиабилеты

**Автор:** Колесов Данил Александрович  
**Этап:** Разработка (Вариант C — веб-страница + backend API)

##  Описание проекта
Веб-приложение для прогнозирования спроса на авиабилеты и расчёта оптимальной цены. 
Пользователь вводит маршрут, дату и цену, а система на основе данных из my_forecast.csv 
выдаёт прогноз продаж (медиану), количество свободных мест и строит график распределения спроса.

##  Реализованные функции (Вариант C)
- **Простое прогнозирование**: форма ввода (откуда, куда, дата, цена) и вывод числа мест и прогноза продаж.
- **График распределения спроса**: визуализация квантилей от 0.1 до 0.9 и линии вместимости самолёта.
- **Регистрация и авторизация**: создание пользователя и вход с использованием токена (Bearer).
- **Backend API**: FastAPI обрабатывает запросы и производит расчёты на лету.
- **Хостинг**: приложение развёрнуто на платформе Timeweb Cloud (ссылка ниже).

##  Технологии
- **Backend**: Python, FastAPI, NumPy, Matplotlib, Passlib (bcrypt).
- **Frontend**: HTML, CSS, JavaScript (Fetch API).
- **Данные**: CSV-файлы (`routes.csv`, `my_forecast.csv`).
- **AI-инструменты**: deepseek (проектирование архитектуры, генерация шаблонов кода, проверка формул).

##  Структура проекта
- `app.py` — основной код backend (FastAPI).
- `requirements.txt` — зависимости Python.
- `static/` — фронтенд (HTML, CSS, JS).
- `data/` — исходные данные (CSV).
